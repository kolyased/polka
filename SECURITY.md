# Безопасность

Полка рассчитана на личную библиотеку одного владельца. Используйте HTTPS, закрытый порт приложения, актуальный Node.js и согласованные резервные копии. Проверка Origin и cookie не заменяет защиту машины и браузера.

Не добавляйте в Git `.env`, ключи, данные библиотеки, SQLite, сессии и аудиофайлы. `.gitignore` и `.dockerignore` содержат базовые исключения; перед отправкой проверяйте `git diff --cached` и историю.

Для сообщения об уязвимости используйте приватное сообщение владельцу репозитория или GitHub Private Vulnerability Reporting, если он включён. Не публикуйте пароли, токены и пользовательские данные в issue.

Автоматические проверки не являются гарантией отсутствия уязвимостей. Офлайн-данные не шифруются. Пользователь с доступом к профилю браузера или серверному тому может прочитать библиотеку. Состояние владельца и сессий хранится в SQLite; защита и восстановление этих данных остаются обязанностью администратора.
